# Assets do Aqualerta

Coloque aqui os arquivos de fonte e ícones.

## Fontes requeridas (Space Grotesk + JetBrains Mono)

Baixe gratuitamente em:
- https://fonts.google.com/specimen/Space+Grotesk  → SpaceGrotesk-*.ttf
- https://fonts.google.com/specimen/JetBrains+Mono → JetBrainsMono-Regular.ttf

Coloque os arquivos .ttf em:
  assets/fonts/SpaceGrotesk-Light.ttf
  assets/fonts/SpaceGrotesk-Regular.ttf
  assets/fonts/SpaceGrotesk-Medium.ttf
  assets/fonts/SpaceGrotesk-SemiBold.ttf
  assets/fonts/SpaceGrotesk-Bold.ttf
  assets/fonts/JetBrainsMono-Regular.ttf

## Ícones SVG

Coloque ícones SVG customizados em assets/icons/

## Animações Lottie

Coloque animações .json em assets/animations/
Sugestão: https://lottiefiles.com/search?q=water+drop
